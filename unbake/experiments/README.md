# Feasibility experiments

| File | Question |
|---|---|
| `latent_ceiling.py` | How well can the TRELLIS.2 texture latent represent the ground-truth materials? |
| `lighting_model.py` | How much of the bake does Lambertian shading under SH lighting with visibility explain? |
| `rebake_discrimination.py` | Does the rebake error rank candidate materials by their albedo error? |
| `decoder_backprop.py` | Memory and time of backpropagation through the texture decoder. |
| `confidence.py` | Does the spread of per-view 2D predictions predict their error? |
| `specular_signal.py` | Do the bakes contain information about roughness and metallic? |
| `results/` | Results on subset 1 (specular signal: subsets 1 and 2). |
